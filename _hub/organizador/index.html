Organizador de documentos

Reúna os documentos do cliente, anexados ou em pastas do Google Drive, em um único PDF, com capas numeradas (Doc. 1, Doc. 2…) na identidade do escritório, ementas descritivas e a correção de orientação das imagens. Também refaz as capas de um PDF de anexos já montado, sem tocar no conteúdo.

Passo 1 Documentos

PDFs e imagens (JPG, PNG). Cada arquivo começa como um documento; depois você pode agrupar frente e verso ou partes de um mesmo ato sob uma única capa.

Arraste os arquivos aqui ou clique para selecionarPDF, JPG ou PNG
Configuração do acesso ao Google Drive

O navegador só consegue ler o Drive com uma credencial do Google. No Google Cloud Console, crie um projeto, ative a Google Drive API e, em Credenciais, gere uma chave de API restrita ao site viniciuspapapapa.github.io e à Drive API. Para arquivos privados, crie também um ID do cliente OAuth do tipo “Aplicativo da Web”, com a origem https://viniciuspapapapa.github.io, e configure a tela de consentimento como interna ao domínio do escritório (ou inclua os usuários como testadores).

As credenciais ficam somente neste navegador. Os arquivos são baixados do Google diretamente para o navegador, sem passar por outro servidor.

Passo 2 Classificação e ordem

Confira a ordem, os títulos, os complementos e as ementas antes de gerar. A classificação automática preenche esses campos a partir do conteúdo de cada documento.

Passo 2 Capas do PDF montado

Marque as páginas que são capas (as prováveis são marcadas automaticamente). Somente essas páginas serão substituídas pelo padrão institucional; todas as demais permanecem intactas.

Passo 3 Rodapé e arquivo
