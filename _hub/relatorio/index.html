Relatório processual ao cliente

Base de processos do escritório alimentada por planilha e atualizada no DataJud, a base pública do CNJ. Os andamentos são traduzidos para linguagem acessível e geram um relatório no padrão TPC, que pode ser editado na própria tela e enviado ao cliente pelo Outlook ou pelo WhatsApp.

Conexão com o DataJud

A consulta passa pelo serviço intermediário do escritório no Cloudflare, porque o DataJud não aceita consultas feitas diretamente pelo navegador. O acesso já vem configurado no HUB; preencha os campos abaixo apenas para usar outro endereço ou outra senha neste navegador.

Quem assina

Para alterar qualquer trecho, clique em Editar texto e escreva diretamente no documento ao lado. A tecla Enter cria novo parágrafo; apagar todo o texto de um parágrafo o retira do documento.

Envio ao cliente

Envio imediato pela conta Microsoft 365 do advogado, com o relatório anexado e cópia em Itens Enviados.

Baixa um e-mail pronto (destinatário, assunto, texto e anexo) que o Outlook do computador abre como mensagem nova. Não exige configuração.

Abre o WhatsApp com o resumo da situação de cada processo já escrito; o arquivo Word, se desejado, é anexado na própria conversa.

Configuração do Outlook (Microsoft 365)

O envio automático usa a permissão Mail.Send de um aplicativo registrado no Microsoft Entra ID do escritório, com plataforma Single-page application e endereço de retorno . O roteiro está no arquivo README do HUB.
